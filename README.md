# טייסת 1945 ✈️

משחק מטוסים משפחתי בעברית – 8 שלבים, 8 בוסים, האנגר עם שדרוגים, ושמירת התקדמות לפי שם שחקן.

## העלאה ל-GitHub Pages
1. ב-GitHub: **New repository** → שם: `tayeset1945` → **Public** → Create.
2. **Add file → Upload files** → לגרור את כל התוכן של התיקייה (כל הקבצים, אין תיקיות) → **Commit changes**.
3. **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `(root)` → **Save**.
4. אחרי דקה-שתיים המשחק זמין בכתובת:
   `https://<שם-המשתמש>.github.io/tayeset1945/`

## התקנה בטלפון
- **אייפון (Safari):** לפתוח את הכתובת → כפתור השיתוף ⬆️ → **הוסף למסך הבית**.
- **אנדרואיד (Chrome):** לפתוח את הכתובת → תפריט ⋮ → **התקן אפליקציה** / **הוסף למסך הבית**.

אחרי הפתיחה הראשונה המשחק עובד גם בלי אינטרנט.

## עדכון המשחק
1. להעלות את `index.html` החדש (Upload files → Commit).
2. ב-`sw.js` להעלות את מספר הגרסה: `tayeset1945-v2` → `tayeset1945-v3`.
3. בטלפון: לסגור ולפתוח את האפליקציה (לפעמים פעמיים).

## הערה על שמירה
ההתקדמות נשמרת בטלפון עצמו. באייפון, האפליקציה ממסך הבית שומרת בנפרד מ-Safari, ולכן התקדמות ששוחקה בדפדפן לא תופיע באפליקציה.
